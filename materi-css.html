BAB 1: Sintaksis dan Cara Kerja

CSS adalah bahasa yang kita gunakan untuk memberikan instruksi gaya kepada browser. Struktur dasarnya terdiri dari Selector (apa yang diubah) dan Declaration Block (perubahan apa yang dilakukan).

CSS bukan sekadar mewarnai. Nama Cascading berarti aturan yang "jatuh bertingkat". Jika ada dua perintah untuk satu elemen, browser akan memilih berdasarkan urutan atau kekuatan (Specificity).

Tiga Cara Memasang CSS:

  • External CSS: Menggunakan file terpisah .css (Paling disarankan).
  • Internal CSS: Menulis di dalam tag <style> di dalam HTML.
  • Inline CSS: Menulis langsung di atribut elemen (Hanya untuk darurat).
/* Selector { Property: Value; } */
p {
  color: blue; /* Mengubah warna teks */
  text-align: center; /* Rata tengah */
}

BAB 2: Selector, Class, dan ID

Agar bisa menghias elemen dengan spesifik, kita perlu memahami perbedaan target selector.

Jenis Selector Utama:

  1. Tag Selector: Menargetkan semua tag tertentu (contoh: h1).
  2. Class Selector: Menargetkan kelompok elemen (ditandai dengan titik .nama-kelas).
  3. ID Selector: Menargetkan satu elemen unik (ditandai dengan pagar #nama-id).
/* Semua paragraf jadi abu-abu */
p { color: gray; }

/* Hanya elemen dengan class 'penting' yang jadi tebal */
.penting { font-weight: bold; }

/* Hanya ID 'logo' yang punya lebar 100px */
#logo { width: 100px; }
Contoh Hover Effect CSS3
.btn-login { background: blue; }
/* Efek saat mouse lewat */
.btn-login:hover { background: darkblue; cursor: pointer; }
Tips: Gunakan Class (.) jika ingin menghias banyak elemen, gunakan ID (#) hanya untuk satu elemen unik.

BAB 3: Memahami Box Model

Setiap elemen HTML adalah kotak. Memahami Box Model adalah kunci agar layout website Anda tidak berantakan.

Komponen Box Model:

  • Content: Isi teks atau gambar.
  • Padding: Ruang kosong di dalam kotak (antara konten dan garis tepi).
  • Border: Garis tepi kotak.
  • Margin: Ruang kosong di luar kotak (jarak antar elemen).
.kotak {
  width: 300px;
  padding: 20px; /* Jarak dalam */
  border: 5px solid black;
  margin: 50px; /* Jarak luar */
}
Mencegah Kotak Meluber CSS3
* { box-sizing: border-box; }
/* Properti wajib agar padding tidak menambah lebar kotak! */

BAB 4: Tipografi dan Warna

Visual yang baik dimulai dari keterbacaan teks dan harmoni warna.

body {
  font-family: 'Roboto', sans-serif;
  font-size: 16px;
  line-height: 1.8; /* Membuat teks tidak rapat */
  color: #333333; /* Warna Hexadecimal */
  background-color: rgba(0,0,0,0.05); /* Warna dengan transparansi */
}

BAB 5: Flexbox (Tata Letak Modern)

Flexbox menghilangkan kerumitan dalam mengatur posisi elemen agar sejajar atau rata tengah.

Lupakan cara lama menggunakan float. Flexbox adalah standar industri untuk membuat layout yang sejajar dengan rapi.

Istilah Penting Flexbox:

  • justify-content: Mengatur posisi horizontal (kiri, kanan, tengah, sebar).
  • align-items: Mengatur posisi vertikal (atas, bawah, tengah).
  • flex-direction: Mengatur arah elemen (baris atau kolom).
.parent {
  display: flex;
  justify-content: space-between; /* Jarak antar item otomatis */
  align-items: center; /* Rata tengah vertikal */
}
Membuat Navbar Sejajar CSS3
.navbar {
  display: flex;
  justify-content: space-between; /* Jarak rata kiri-kanan */
  align-items: center; /* Rata tengah secara vertikal */
}

BAB 6: Media Queries (Web Responsif)

Teknik ini memungkinkan website berubah tampilan secara otomatis tergantung ukuran layar perangkat pengguna.

/* Tampilan Desktop Utama */
.menu { display: flex; }

/* Perubahan untuk HP (Layar di bawah 600px) */
@media (max-width: 600px) {
  .menu { flex-direction: column; }
  body { font-size: 14px; }
}
Kondisi Smartphone CSS3
@media (max-width: 768px) {
  .container { flex-direction: column; }
  .sidebar { display: none; } /* Sembunyikan menu di HP */
}
