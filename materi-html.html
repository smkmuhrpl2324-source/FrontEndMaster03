BAB 1: Memahami Cara Kerja HTML

HTML adalah bahasa standar untuk membuat halaman web. HTML menggunakan Tag untuk memberi tahu browser bagaimana konten harus ditampilkan.

Struktur Dasar Dokumen

Setiap dokumen HTML dimulai dengan <!DOCTYPE html>. Ini bukan tag, melainkan instruksi kepada browser bahwa kita menggunakan standar HTML5 terbaru.

<html lang="id">
  <head>
    <meta charset="UTF-8">
    <title>Judul Halaman</title>
  </head>
  <body>
    <h1>Halo Dunia!</h1>
  </body>
</html>

BAB 2: Elemen Teks dan Formatting

Teks adalah konten utama di web. Kita harus mengatur hierarki informasi agar mudah dibaca oleh manusia dan Google.

Heading (Judul)

Ada 6 tingkat heading, dari <h1> sampai <h6>. Gunakan <h1> hanya satu kali untuk judul utama halaman.

Paragraf dan Penekanan

Gunakan tag <p> untuk paragraf. Untuk menebalkan, gunakan <strong> (penting secara makna) atau <b> (penting secara visual).

<p>Ini adalah <strong>teks penting</strong> di dalam paragraf.</p>

BAB 3: Media (Gambar & Multimedia)

Sebuah website akan terasa membosankan jika hanya berisi teks. Di sini kita akan belajar cara menyisipkan gambar, audio, dan video.

1. Menampilkan Gambar (<img>)

Tag gambar tidak memiliki penutup. Dua hal penting yang harus ada adalah src (lokasi file) dan alt (teks pengganti).

<img src="foto-siswa.jpg" alt="Foto Siswa SMK" width="300">

2. Video dan Audio

HTML5 memudahkan kita memutar musik atau film langsung di browser tanpa aplikasi tambahan.

BAB 4: Tabel dan List

List digunakan untuk poin-poin, sedangkan Tabel untuk data statistik atau jadwal pelajaran.

Unordered List (<ul>) vs Ordered List (<ol>)

  • <ul>: Menggunakan simbol (bulat/kotak).
  • <ol>: Menggunakan urutan angka atau huruf.

Tabel Modern

<table border="1">
  <tr>
    <th>No</th><th>Mata Pelajaran</th>
  </tr>
  <tr>
    <td>1</td><td>Pemrograman Web</td>
  </tr>
</table>

BAB 5: Form dan Input User

Ini adalah bagian interaksi. Form memungkinkan siswa mengirim data ke server.

Elemen Form Utama

  • <input type="text">: Untuk nama atau username.
  • <input type="email">: Memastikan input berformat email.
  • <input type="password">: Menyembunyikan karakter saat diketik.
  • <textarea>: Untuk pesan panjang/komentar.
  • <select>: Membuat menu pilihan (dropdown).
<form action="/simpan" method="POST">
  <label>Email:</label>
  <input type="email" name="user_email" required>
  <button type="submit">Daftar Sekarang</button>
</form>

BAB 6: Struktur Semantik HTML5

Ini adalah standar industri saat ini. Jangan gunakan <div> untuk semua hal!

Tag semantik membuat kode lebih rapi:

  • <header>: Bagian atas (Logo & Nav).
  • <nav>: Kumpulan link navigasi.
  • <main>: Isi unik dari halaman web.
  • <article>: Konten yang bisa berdiri sendiri (seperti postingan blog).
  • <section>: Kelompok konten yang saling berkaitan.
  • <aside>: Bagian samping (iklan, link populer).
  • <footer>: Kaki web (hak cipta, kontak).

Mengapa Semantik Penting?

Semantik membantu mesin pencari (SEO) dan alat pembaca layar (untuk tunanetra) memahami mana bagian navigasi, mana bagian artikel, dan mana bagian penutup.

Contoh Penerapan Semantik

Perhatikan bagaimana struktur ini lebih mudah dibaca oleh mesin dan manusia:

<header>
  <h1>Logo Sekolah</h1>
  <nav>
    <ul>
      <li><a href="#">Beranda</a></li>
      <li><a href="#">Profil SMK</a></li>
    </ul>
  </nav>
</header>

<main>
  <article>
    <h2>Pengumuman Kelulusan</h2>
    <p>Selamat kepada seluruh siswa kelas XII...</p>
  </article>
  
  <aside>
    <h3>Berita Populer</h3>
    <ul>
      <li>Lomba Coding SMK 2026</li>
    </ul>
  </aside>
</main>

<footer>
  <p>&copy; 2026 Lab Komputer SMK</p>
</footer>
Tips Guru: Bayangkan tag semantik seperti label pada laci. Tanpa label, kita harus membuka semua laci untuk mencari baju. Dengan label (semantik), browser dan Google langsung tahu di mana letak konten utamanya!
