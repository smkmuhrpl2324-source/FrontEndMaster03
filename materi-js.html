🚀 Modul 3: JavaScript

Memberikan Logika dan Interaksi pada Halaman Web.

BAB 1: Variabel (Tempat Penyimpanan)

Variabel adalah wadah untuk menyimpan data. Bayangkan variabel sebagai sebuah kotak berlabel yang berisi nilai tertentu.

Contoh Variabel JS
let namaSiswa = "Budi"; // Menyimpan teks (String)
const nilaiKoding = 95; // Nilai tetap (Angka/Number)
alert(namaSiswa); // Memunculkan kotak pesan

BAB 2: Tipe Data (Jenis-Jenis Nilai)

JavaScript membagi data menjadi beberapa jenis utama. Mengetahui tipe data membantu kita menghindari kesalahan logika saat menghitung atau mengolah teks.

Contoh Penulisan Tipe Data JS
// 1. String (Teks) - Harus dibungkus tanda kutip
let kota = "Jakarta";

// 2. Number (Angka) - Tanpa tanda kutip
let umur = 17;

// 3. Boolean (Logika) - Hanya true atau false
let isLogin = true;

BAB 3: Pengkondisian (Logika IF)

Inilah inti dari kecerdasan komputer. Program bisa mengambil keputusan berdasarkan situasi tertentu.

Logika Kelulusan JS
if (nilai > 75) {
  console.log("Selamat, kamu lulus!");
} else {
  console.log("Semangat, coba lagi ya.");
}

BAB 4: Manipulasi DOM (Mengubah HTML)

JavaScript bisa mengubah isi HTML secara langsung tanpa harus refresh halaman. Inilah yang membuat web terasa "hidup".

DOM adalah representasi struktur HTML dalam bentuk pohon (tree). Dengan DOM, JavaScript bisa mengakses setiap elemen seperti mengakses cabang pohon.

// Mengambil elemen lalu mengganti teksnya
document.getElementById("judul").innerText = "Halo Dunia!";

1. Menyeleksi Elemen (Finding)

let judul = document.getElementById("header");
let tombol = document.querySelector(".btn-biru");

2. Mengubah Isi & Properti (Changing)

judul.innerText = "Selamat Datang di SMK!";
judul.innerHTML = "<i>Teks Miring</i>";
gambar.src = "foto-baru.jpg";

3. Mengubah Gaya (Styling)

judul.style.color = "red";
judul.style.backgroundColor = "yellow";

BAB 5: Function (Fungsi)

Function adalah sekumpulan instruksi yang dibungkus jadi satu. Bayangkan seperti Resep Masakan.

Cara Membuat Fungsi JS
function sapaSiswa(nama) {
  return "Halo " + nama + ", selamat belajar!";
}

console.log(sapaSiswa("Andi"));

BAB 6: Event Listener (Sensor Interaksi)

JavaScript bertugas sebagai Sirine yang menunggu perintah dari Bel (Event).

  • 🎯 Target: Tombol, Gambar, Input.
  • ⚡ Event: Klik, Ketik, Geser.
  • 🎬 Action: Munculkan pesan, ubah warna.
elemen.addEventListener("click", function() {
  // Jalankan kode...
});

BAB 7: Penerapan Nyata (Saklar Lampu)

Gabungan Variabel, Event Listener, dan Manipulasi DOM.

Contoh Kode Lengkap JS
let lampuMenyala = false;
const tombol = document.querySelector("#saklar");
const lampu = document.querySelector("#bohlam");

tombol.addEventListener("click", function() {
  if (!lampuMenyala) {
    lampu.src = "lampu-on.png";
    lampuMenyala = true;
  } else {
    lampu.src = "lampu-off.png";
    lampuMenyala = false;
  }
});
